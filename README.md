# 🤖 Claude AI Telegram Bot

একটি ফাইলের (`bot.py`) ভেতরে সম্পূর্ণ টেলিগ্রাম বট, যা Claude (Anthropic API) দিয়ে চলে। এতে আছে অ্যাকাউন্ট সিস্টেম, প্রিমিয়াম, নিজের API Key সেটআপ আর রঙিন বাটন মেনু।

> **মনে রাখবেন:** `claude.ai/chat` ওয়েবসাইট বট থেকে সরাসরি ব্যবহার করা যায় না। বটটি Anthropic API ব্যবহার করে, যার জন্য আলাদা API key ও ব্যবহার অনুযায়ী বিলিং লাগে।

## 🚀 ইনস্টল ও চালানোর ধাপ

### ধাপ ১: বট তৈরি
1. টেলিগ্রামে `@BotFather` খুলুন
2. `/newbot` দিন, নাম ও ইউজারনেম দিন
3. যে টোকেন পাবেন সেটি কপি করুন

### ধাপ ২: API key নিন
1. [console.anthropic.com](https://console.anthropic.com) এ লগইন করুন
2. **API Keys** থেকে নতুন key তৈরি করুন (`sk-ant-…` দিয়ে শুরু হয়)
3. বিলিংয়ে ক্রেডিট যোগ করুন

### ধাপ ৩: লাইব্রেরি ইনস্টল
```bash
pip install "python-telegram-bot>=20" anthropic aiohttp
```

### ধাপ ৪: কনফিগারেশন
`bot.py` এর উপরের **ধাপ ১: কনফিগারেশন** অংশে নিজের তথ্য বসান:

```python
BOT_TOKEN = "আপনার_বট_টোকেন"
OWNER_API_KEY = "sk-ant-..."
ADMIN_IDS = {123456789}          # আপনার টেলিগ্রাম আইডি
PREMIUM_CONTACT = "@your_username"
```

অথবা ফাইল না বদলে Environment Variable ব্যবহার করুন:

```bash
export BOT_TOKEN="..."
export ANTHROPIC_API_KEY="sk-ant-..."
export ADMIN_IDS="123456789"
export PREMIUM_CONTACT="@your_username"
```

### ধাপ ৫: চালান
```bash
python bot.py
```
টার্মিনালে `🚀 বট চালু হয়েছে!` দেখলে সফল।

### ধাপ ৬: টেস্ট
1. বটে `/start` দিন
2. একটা প্রশ্ন লিখুন
3. `/admin` দিয়ে অ্যাডমিন কমান্ডগুলো দেখুন

অ্যাডমিন হিসেবে `/admin` দিন, অথবা `/start` দিলে মূল মেনুতে **👑 Admin Panel** বাটন দেখা যাবে। সব সেটিং বাটন চেপে বোর্ড থেকেই বদলানো যায়, ফাইল এডিট বা রিডিপ্লয় লাগে না।

| বাটন | কাজ |
|---|---|
| 🔑 API Key | বটের Anthropic API key সেট বা বদল (যাচাই করে সেভ হয়, মেসেজ মুছে যায়) |
| 🖼 Channel Logo | লোগো ছবি পাঠালে `/start` স্ক্রিনের উপরে দেখাবে |
| 🔗 Channel Link | লিংক দিলে মূল মেনুতে **📢 Join Our Channel** বাটন আসবে |
| 📞 Premium Contact | প্রিমিয়াম কিনতে যোগাযোগের ইউজারনেম |
| 📊 Free Limit | ফ্রি ইউজারের দৈনিক মেসেজ সীমা |
| 📈 Stats | ইউজার ও প্রিমিয়ামের পরিসংখ্যান |
| 💎 Grant Premium | `user_id দিন` লিখে প্রিমিয়াম দেওয়া |

প্রতিটি সেটিং-এর স্ক্রিনে **✏️ Change** ও **🗑 Remove / Reset** বাটন আছে। বোর্ডের সেটিং ফাইলের মানের চেয়ে অগ্রাধিকার পায়।

> **Railway-তে জরুরি:** সেটিংগুলো ডাটাবেসে (`bot.db`) জমা থাকে। Volume না থাকলে রিডিপ্লয়ে এগুলো মুছে যাবে। Railway-তে একটি Volume যোগ করুন (যেমন `/data`) এবং Variables-এ `DB_PATH=/data/bot.db` দিন।

## 🛒 প্রিমিয়াম প্ল্যান ও অটো পেমেন্ট ভেরিফিকেশন

| প্ল্যান | দাম |
|---|---|
| 1 Day | 50 TK |
| 7 Days | 250 TK |
| 28 Days | 400 TK |
| 90 Days | 600 TK |
| 120 Days | 1200 TK |

(দাম বদলাতে `bot.py`-এর উপরের `PLANS` লাইন এডিট করুন।)

### ইউজার যেভাবে কেনে
1. **Premium → 🛒 Buy Premium** চেপে প্ল্যান বাছে
2. দেখানো নম্বরে (bKash/Nagad/Rocket) **Send Money** করে
3. **✅ I've Paid** চেপে SMS-এর **TrxID** কপি করে পেস্ট করে
4. পেমেন্ট মিললে প্রিমিয়াম **নিজে নিজে চালু** হয়ে যায়

### অটো ভেরিফাই কীভাবে কাজ করে
আপনার যে ফোনে টাকা আসে, সেই ফোনের "Money Received" SMS একটি SMS-ফরওয়ার্ডার অ্যাপ দিয়ে বটের webhook-এ পাঠানো হয়। বট SMS থেকে **TrxID ও পরিমাণ** পড়ে ইউজারের জমা দেওয়া TrxID-র সাথে মেলায়।

- TrxID মিললে এবং টাকা প্ল্যানের দামের সমান বা বেশি হলে → **সাথে সাথে অ্যাপ্রুভ**
- ইউজার আগে TrxID দিলে, SMS পরে এলে → SMS আসার মুহূর্তেই অ্যাপ্রুভ
- টাকা কম হলে → রিজেক্ট, ইউজার মিল রেখে অন্য প্ল্যান বাছতে পারে
- একই TrxID দ্বিতীয়বার ব্যবহার করা যায় না
- SMS না এলে অর্ডার **pending** থাকে এবং আপনি অ্যাডমিন প্যানেলে ✅ Approve / ❌ Reject করতে পারেন

### সেটআপের ধাপ
1. **Railway-তে ডোমেইন চালু করুন:** Service → Settings → Networking → **Generate Domain**
2. `/admin` → **💳 Payments** খুলুন
3. bKash / Nagad / Rocket নম্বর সেট করুন
4. স্ক্রিনে দেখানো **SMS Webhook URL** কপি করুন (শেষে `?secret=...` থাকবে, কাউকে দেবেন না)
5. টাকা আসে এমন ফোনে একটি **SMS ফরওয়ার্ডার অ্যাপ** ইনস্টল করুন। সেখানে:
   - পাঠানোর ঠিকানা (URL) = ওই Webhook URL, মেথড = **POST**
   - ফিল্টার: শুধু bKash / Nagad / Rocket থেকে আসা SMS
6. **🧪 Test SMS Parser** চেপে একটি আসল "Money Received" SMS পেস্ট করুন। বট TrxID ও পরিমাণ ঠিকভাবে পড়তে পারলে সেটআপ ঠিক আছে।
7. নিজের আরেকটি নম্বর থেকে ১ দিনের প্ল্যান (50 TK) কিনে পুরো প্রক্রিয়া একবার পরীক্ষা করুন।

### ⚠️ জেনে রাখুন
- SMS ফরওয়ার্ডার ফোনে চালু ও ইন্টারনেটসহ থাকতে হবে। ফোন বন্ধ থাকলে অর্ডার pending থাকবে, তখন ম্যানুয়ালি অ্যাপ্রুভ করুন।
- SMS-এর ভাষা ভিন্ন হলে (যেমন নতুন ফরম্যাট) 🧪 Test SMS Parser-এ ধরা পড়বে। সেই SMS আমাকে পাঠালে পার্সার ঠিক করে দেব।
- Railway Volume ছাড়া রিডিপ্লয়ে অর্ডার ও পেমেন্টের ডেটা মুছে যাবে। `DB_PATH=/data/bot.db` সেট করতে ভুলবেন না।
- `PUBLIC_URL` Variable দিয়ে নিজের ডোমেইন সেট করা যায়, না দিলে Railway-র ডোমেইন নিজে থেকে নেওয়া হয়।

## 🔐 Google অ্যাকাউন্ট দিয়ে লগইন

ইউজার মূল মেনুর **🔐 Login with Google** (বা Account স্ক্রিন) চেপে Google দিয়ে লগইন করতে পারে। লগইন হলে Google অ্যাকাউন্টটি তার টেলিগ্রাম অ্যাকাউন্টের সাথে যুক্ত হয়। পরে নতুন টেলিগ্রাম অ্যাকাউন্ট থেকে একই Google দিয়ে ঢুকলে **প্রিমিয়াম, API key ও মোড** নতুন অ্যাকাউন্টে চলে আসে (পুরনোটি থেকে সরে যায়)। **🚪 Unlink Google** দিয়ে যেকোনো সময় সংযোগ বিচ্ছিন্ন করা যায়।

### সেটআপ (একবারই)
1. [console.cloud.google.com](https://console.cloud.google.com) → **APIs & Services → Credentials → Create Credentials → OAuth client ID**
2. Application type: **Web application**
3. **Authorized redirect URIs**-এ এটি দিন (আপনার ডোমেইন বসিয়ে):
   ```
   https://আপনার-ডোমেইন/google/callback
   ```
4. যে **Client ID** ও **Client Secret** পাবেন সেগুলো বটের `/admin` → **🔐 Google Client ID** ও **🔑 Google Secret** বাটনে দিন (অথবা `GOOGLE_CLIENT_ID` ও `GOOGLE_CLIENT_SECRET` Variable)
5. Railway-তে **Generate Domain** করা থাকতে হবে (SMS webhook-এর মতোই), না হলে `PUBLIC_URL` Variable দিন

> Admin-এর Google বাটনের স্ক্রিনেই redirect URI দেখানো আছে, কপি করে নিতে পারবেন।

### জেনে রাখুন
- লগইন লিংক একবার ব্যবহার করা যায় এবং ১০ মিনিট পর মেয়াদ শেষ হয়
- শুধু **ভেরিফায়েড Google ইমেইল** গ্রহণ হয়
- টেলিগ্রামের ভেতরের ব্রাউজারে Google কখনো লগইন আটকায়। তখন ⋮ → **Open in browser** চেপে Chrome-এ খুলুন
- OAuth consent screen "Testing" মোডে থাকলে শুধু Test users-এর Google অ্যাকাউন্ট ঢুকতে পারবে। সবাইকে দিতে **Publish app** করুন

## 🌐 Third-Party API সিস্টেম

বটটি এখন Anthropic-এর অফিসিয়াল API ছাড়াও যেকোনো **Third-Party API প্রোভাইডার** (প্রক্সি/গেটওয়ে/রিসেলার) দিয়ে চলে। শর্ত: প্রোভাইডারকে **Anthropic ফরম্যাট** (`/v1/messages`) অথবা **OpenAI ফরম্যাট** (`/v1/chat/completions`) সাপোর্ট করতে হবে।

> `claude.ai` ওয়েবসাইটের লগইন/সাবস্ক্রিপশন বটে ব্যবহার করা যায় না। এর জন্য কোনো অফিসিয়াল API নেই। তাই প্রোভাইডারের API key + URL ব্যবহার করতে হয়।

### অ্যাডমিন (বটের নিজের API)
`/admin` → **🔑 API Key** দিয়ে প্রোভাইডারের key দিন, তারপর:

| বাটন | কাজ |
|---|---|
| 🌐 API Base URL | প্রোভাইডারের URL (যেমন `https://api.example.com`)। Remove করলে অফিসিয়াল Anthropic |
| 🤖 Model | প্রোভাইডারের দেওয়া মডেলের নাম |
| 🔀 API Format | `anthropic` (ডিফল্ট) বা `openai` |

URL সেভ করলেই বট নিজে কানেকশন টেস্ট করে জানিয়ে দেয়।

### ইউজার (নিজের Third-Party API)
**Account → 🌐 Third-Party API** (বা Premium স্ক্রিনে একই বাটন) চেপে এক মেসেজে পাঠান:

```
https://api.example.com  YOUR_KEY  claude-sonnet-5-5  openai
```

- শেষের `openai` শুধু তখনই দিন যখন প্রোভাইডার OpenAI ফরম্যাট ব্যবহার করে
- মডেল না দিলে ডিফল্ট মডেল ব্যবহার হয়
- বট মেসেজটি মুছে দেয়, কানেকশন টেস্ট করে, তারপর সেভ করে
- সেভ হলে ইউজার আনলিমিটেড ব্যবহার পায়

### Environment Variable (ঐচ্ছিক)
| ভেরিয়েবল | কাজ |
|---|---|
| `API_BASE_URL` | বটের নিজের Third-Party URL |
| `API_FORMAT` | `anthropic` বা `openai` |

## 🔒 নিরাপত্তা

- ইউজার API key পাঠালে বট মেসেজটি সাথে সাথে মুছে দেয়।
- key গুলো `bot.db` ফাইলে সাধারণ টেক্সটে জমা থাকে। ফাইলটি সুরক্ষিত রাখুন এবং কাউকে শেয়ার করবেন না।
- `bot.py` বা `bot.db` GitHub-এ আপলোড করবেন না। আপলোড করলে আগে টোকেন ও key সরিয়ে নিন।
- বেশি ইউজার থাকলে Anthropic ড্যাশবোর্ডে খরচ নিয়মিত দেখুন।

## ☁️ সবসময় চালু রাখা

কম্পিউটার বন্ধ হলে বটও বন্ধ হয়ে যায়। সবসময় চালু রাখতে VPS বা Railway/Render-এর মতো হোস্টিং ব্যবহার করুন। Linux সার্ভারে `screen` বা `systemd` দিয়ে চালানো যায়:

```bash
screen -S bot
python bot.py
# Ctrl+A তারপর D চাপলে ব্যাকগ্রাউন্ডে চলবে
```

## 🛠 সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `BOT_TOKEN বসান` এরর | কনফিগে সঠিক টোকেন বসান |
| বট উত্তর দেয় না | `ANTHROPIC_API_KEY` ঠিক আছে কি না এবং বিলিংয়ে ক্রেডিট আছে কি না দেখুন |
| `API Key সঠিক নয়` | key আবার কপি করুন, শুরুতে `sk-ant-` আছে কি না দেখুন |
| `/admin` কাজ করে না | `ADMIN_IDS` এ আপনার সঠিক আইডি আছে কি না দেখুন |
| `/grant` এ ইউজার পাওয়া যায় না | ইউজারকে আগে বটে `/start` দিতে হবে |
| মডেলের এরর | `CLAUDE_MODEL` বদলে Anthropic ডকুমেন্টেশনে দেওয়া সচল মডেলের নাম দিন |
